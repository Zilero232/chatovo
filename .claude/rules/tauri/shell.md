# Tauri shell

- The shell wraps the static client export; no UI lives here. Desktop features are written on the client behind `isTauri()` — only the tray icon and its native menu are owned by Rust (`src/tray_menu.rs`).
- `bun run lint:rust` (clippy with `-D warnings`) and `bun run format:rust` must pass. The toolchain comes from `mise.toml` (`mise install`), not a `rust-toolchain.toml`.
- The updater is desktop-only at three layers: `cfg(not(android))` in `Cargo.toml`, `#[cfg(desktop)]` in `lib.rs`, `updater:default` only in `capabilities/desktop.json`. Play forbids in-app updates.
- `gen/android/` is regenerated by `tauri android init` and gitignored — never edit it. Android overlays (FCM, signing, manifest permissions) are applied by `scripts/*.mjs` and `build.rs`, anchored on block structure rather than a version string.
- The window icon is linked into the binary: a new icon needs a rebuild, not a `tauri:dev` restart.
